OBS 录制顺序执行指南
====================

工作目录：

  cd /home/siqin/ros2_workspaces/humble/ros2_pybullet_ws/docs

通用规则：

  1. 每录一段前，先执行：

       ./recording_scripts/00_stop_recording_stack.sh

  2. 开始 OBS 录制。
  3. 执行当前段落的启动命令。
  4. 录到需要的画面后，停止 OBS。
  5. 再执行：

       ./recording_scripts/00_stop_recording_stack.sh

  6. 进入下一段。

阶段 1：LLM 任务分解与 prompt 传递
---------------------------------

录制目标：

  展示自然语言任务如何被 LLM 分解为 plan_json，
  并把目标 object / prompt 传递给 SAM3。

建议 OBS 画面：

  - 终端输出
  - /llm_task/status
  - /llm_task/plan_json
  - /sam3/active_prompt
  - 可选：PyBullet GUI，显示整齐排列的银灰色器械和 Franka 抓手

执行顺序：

  cd /home/siqin/ros2_workspaces/humble/ros2_pybullet_ws/docs

  ./recording_scripts/00_stop_recording_stack.sh

  ENABLE_GRIPPER=true \
  GRIPPER_MODEL=franka_hand \
  ./recording_scripts/01a_llm_prompt_stack_start.sh

如果要单独开 topic echo 窗口，新开终端执行：

  cd /home/siqin/ros2_workspaces/humble/ros2_pybullet_ws
  source /opt/ros/humble/setup.bash
  source install/setup.bash
  ros2 topic echo /llm_task/status

再开一个终端：

  cd /home/siqin/ros2_workspaces/humble/ros2_pybullet_ws
  source /opt/ros/humble/setup.bash
  source install/setup.bash
  ros2 topic echo /llm_task/plan_json

再开一个终端：

  cd /home/siqin/ros2_workspaces/humble/ros2_pybullet_ws
  source /opt/ros/humble/setup.bash
  source install/setup.bash
  ros2 topic echo /sam3/active_prompt

OBS 开始录制后，发送任务：

  cd /home/siqin/ros2_workspaces/humble/ros2_pybullet_ws/docs

  ./recording_scripts/01b_llm_prompt_send_task.sh \
    "pick up the left silver surgical instrument and then release it"

录到 plan_json 和 prompt handoff 后停止：

  ./recording_scripts/00_stop_recording_stack.sh
