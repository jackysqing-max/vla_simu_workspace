# v1.3.0 代码整理汇总

整理日期：2026-07-13

## 目标与备份

本次整理以“先备份、后清理”为原则。清理前的可公开源码快照已推送到：

- 远端分支：`backup/pre-cleanup-20260713`
- 备份提交：`6fc5881ddb2136c924d9c5c5d51394809ac37bea`
- 新版本分支：`release/v1.3.0`

备份包含当时所有源码、配置、启动脚本、必要网格和文档改动。公开仓库未上传
医学影像、第三方论文、Office 文件、实验结果和编译缓存。

## 结构整理

### 删除与合并

- 删除根目录和 `src/` 下两套相同的旧 Touchless 原型源码；维护入口统一为
  `src/touchless_project_ros/`。旧源码仍可从备份分支恢复。
- 删除根目录重复的 Touchless 数据副本；本机只保留一份私有资料，且通过
  `.gitignore` 与公开源码隔离。
- 停止跟踪 `run_logs/` 和旧 PID 文件。
- 删除 `docs/phantom_centered.stl`；规范模型位置统一为
  `src/rcm_virtual_fixtures/meshes/phantom_centered.stl`。
- 将三份内容重叠、合计 2600 余行的 RCM 文档合并为
  `docs/RCM_DEMO_GUIDE.md`。
- 将 README 改为面向当前四条维护链路的快速入口，移除过时版本说明和重复命令。

### 本地生成物清理

已删除可重新生成的内容：

- ROS `build/`、`install/`、`log/`
- `run_logs/`、`run_pids/` 和旧 `.run/`
- TorchInductor 编译缓存
- VS Code C/C++ 索引数据库

同时删除了一套逐字节重复的本地 Touchless 资料副本。工作区占用由约 3.8 GB
降至约 265 MB；其中约 174 MB 是仍保留在本机、未进入 Git 的私有参考资料。

## 代码简化与修正

- RCM 四步安全计划的动作参数改为单一默认表，移除 fallback 与 sanitizer 中的
  重复定义。
- 新增 RCM 计划测试，验证动作顺序和运动参数不能被模型输出覆盖。
- Touchless 包不再从相邻旧目录隐式打包 MRI 数据；MRI viewer 只接受显式
  `nifti_path` 或 `TOUCHLESS_PROJECT_NIFTI_PATH`。
- 新增启动脚本不再硬编码用户主目录，工作区和虚拟环境位置可移植、可覆盖。
- 补齐 `iiwa_cpp_controller` 的 `libjsoncpp-dev` 依赖，以及
  `robot_control_msgs` 的 `builtin_interfaces`、`std_msgs` 依赖。
- `.gitignore` 新增 TorchInductor 和本地私有 Touchless 资料规则。
- 清理 4 个既有包的 81 项 flake8 和 8 项 pep257 问题，均为等价格式调整、
  死导入或死变量删除，不改变运行行为。
